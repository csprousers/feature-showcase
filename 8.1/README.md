## CSPro 8.1 Feature Showcases

This branch of the [repository](https://github.com/csprousers/feature-showcase) contains "feature showcases" for CSPro 8.1 and is available to download: [feature-showcase-8.1.zip](https://github.com/csprousers/feature-showcase/archive/refs/heads/8.1.zip).


### JavaScript in Logic

This showcase demonstrates how to execute JavaScript from CSPro logic, including:

* Calling JavaScript built-in functions using JS.eval.
* Calling JavaScript functions using JS.eval, JS.invoke, and function wrappers.
* Use of the Action Invoker from JavaScript.
* CSPro <-> JavaScript value conversions.


### Fetch

This showcase demonstrates how to use actions in the Action Invoker Network to make HTTP requests and handle responses, including:

* Processing the response of calls to APIs that return JSON.
* Downloading files.
* Using request headers.
* Using Action Invoker binary data caching.
